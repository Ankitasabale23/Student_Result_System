Student Result & Grade Management System

1. Project Description

The Student Result & Grade Management System is a Python-based application that manages student details, subject marks, grades, and academic performance. It allows users to add, view, search, and update student records and generate performance summaries.

2. Objectives

- Learn Python fundamentals and functions.
- Manage student records efficiently.
- Calculate total marks, percentages, grades, and results.
- Search and update student information.
- Generate academic performance summaries.

3. Technologies Used

- Python
- JSON file handling
- Dictionaries and lists
- Functions and conditional statements
- Visual Studio Code

4. Features

- Add new student records.
- View all student results.
- Search students using their IDs.
- Update subject marks.
- Calculate total marks and percentage.
- Assign grades and determine pass/fail status.
- Display class average, highest percentage, and lowest percentage.
- Store records permanently in a JSON file.

5. Project Files

- "student_result.py" — Main Python program.
- "students.json" — Automatically created file containing student records.
- "README.md" — Project documentation.

6. How to Run

Open the project folder in VS Code and run the following command in the terminal:

& "C:\Users\Admin\.local\bin\python3.14.exe" student_result.py

No external Python libraries are required.

7. How to Use

1. Run the program.
2. Select an option from the menu.
3. Enter student details and subject marks.
4. View or search for student results.
5. Update marks when required.
6. Generate the performance summary.
7. Select Exit to close the program.

8. Grading System

The program uses the following example grading scale:

Percentage| Grade
90–100%| A+
80–89.99%| A
70–79.99%| B
60–69.99%| C
50–59.99%| D
Below 50%| F

A student passes only if every subject mark is at least 35. These rules can be modified according to institutional requirements.

9. Data Storage

Student information is saved in "students.json". The program loads the saved records when it starts and updates the file whenever student records or marks are changed.
